# EDOS Web Application

The frontend client for the **Enterprise Decision Operating System (EDOS)**, built with Next.js, React, and TypeScript.

## Status

**Day 1: Foundation Phase**
- Establishes the minimal Next.js shell and verified build configuration.
- Operational workspace and UI primitives are scheduled for Day 2.

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

The application will be accessible at [http://localhost:3000](http://localhost:3000).

### Production Build
```bash
npm run build
npm start
```
